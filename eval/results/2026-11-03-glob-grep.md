# Glob and Grep in the agent sessions, 3 November 2026

The agents launched with Glob and Grep named in `--allowedTools`, measured on the same tickets as the writer's rules ([2026-11-02-writer-partitions.md](2026-11-02-writer-partitions.md)).

> **Status: scores checked, transcripts not reviewed yet.** The figures below come from the per-trial summary that each CI job prints in its log. The trial artifacts (transcripts, `trial.json`, the workflow's `eval-report`) could not be downloaded for this report. So it does not yet show whether the Glob and Grep calls succeed, which is the point of the change. See [Not verified yet](#not-verified-yet).

## The change

That report found that Glob and Grep do not exist in the agents' sessions in CI. Every call returned "No such tool available", and the guard refuses `find`, `ls`, `grep` and `cat` in Bash. The only way for the writer to find a file was to Read a path it already knew.

**D** is C, the version in `main`, plus two changes to the kit. The writer's prompt, the model, effort, hooks and settings are unchanged.

- `e2098d5`: `qa/run-qa.sh` and `qa/repair-loop.sh` launch the agent with `--allowedTools 'Glob,Grep'`. On Linux and macOS, Claude Code leaves both tools out of its default set. An allow rule in a settings file does not bring them back. The guard still checks their paths, and the settings' Read deny rules also apply to them.
- `cfdfe07` (#16): phase 1 sends back a unit test that cannot pass on any implementation. That means a jest-dom matcher used without its import, or a failure that comes from the test code itself. C was measured before this check existed.

With D, the sentence C added to the writer ("To find files, use the Glob tool…") names tools that the session does provide.

## Limits

- 6 new tickets × 3 trials, and 10 × 3 for the regression check. 36 of 36 does not mean D never misses.
- D changes two things at once (#16 and `--allowedTools`). This measurement cannot separate their effects.
- C ran on 2 November, D on 3 November. The model behind the `sonnet` alias may not be strictly the same between runs.
- The approval before phase 2 is scripted.
