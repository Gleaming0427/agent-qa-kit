# One case per plausible wrong implementation: rule 5 measured, 4 November 2026

Rule 5 of `.claude/agents/qa-writer.md` asked for "at least one case where a plausible wrong implementation shows a different result". Since commit e9f30f4, it asks for a case for each plausible wrong implementation of each rule a criterion combines, and for the evidence to name the one each case rules out ([2026-11-04-eval-1-ac-1.md](2026-11-04-eval-1-ac-1.md) gives the reason). The examples of the rule did not change.

## The plan, written before the results

Committed before QA eval run 41834419007 (run 35: every ticket, 3 trials, the new prompt) finished, so the reading cannot follow the results.

- **The decision** is the release decision of run 35, under the rules at its commit. The reference is D clean, the release baseline, with run 34 for EVAL-17 (the agent of D clean, 3 trials). The comparison pools each side's trials ticket by ticket.
- **A second reading** pools every campaign of D clean's agent as the reference:
  - D clean;
  - its regression check;
  - the split-runner campaign;
  - smoke runs 30 and 32;
  - follow-up run 33;
  - run 34.

  It gives the reference more trials on the tickets that varied (EVAL-1: 15). It informs; it does not decide.
- **What would show that the rule works:** EVAL-1's bug `discount-includes-shipping` detected more often than D clean's agent did (7 of its 15 trials), with AC-1 cases where shipping is paid. With 3 trials, only a large change can be read: 3/3 against 7/15 is a hint, not a proof. The ticket that revealed the problem cannot validate its fix on its own.
- **What would show a cost:**
  - a ticket or a bug worse on the other tickets;
  - more turns, a longer phase 1, or a higher cost per trial;
  - more false positives, since more cases are more chances to assert something the spec does not say.
- **EVAL-17** was written after reading EVAL-1's misses, as a ticket the new rule was not tuned on. The agent of D clean already passed it 3/3, with every bug detected (run 34). It can show a loss, not a gain.
- **Nothing is concluded** from a single campaign where the trials disagree. A ticket that gets worse gets one follow-up, as the release decision asks.
